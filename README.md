# MittConnect
MittConnect is a protocol for connecting show- or studio-equipment of all kinds

This is just a concept at the moment and will probably grow together with my OpenDJ-Standalone project. The goal of this project is to create a universal and extensible protocol that allows connection, syncronization and communication between show-equipment like DMX-Controllers, High-End-Mixers, DJ- and VJ-Gear and everything that you can imagine in relation to this.
